Грабли этой машины:

- **Не ставить `MSYS_NO_PATHCONV=1` при вызове `./gradlew` из Git Bash** — скрипт ломается
  с «Could not find or load main class GradleWrapperMain». Для `adb shell … /sdcard/…`
  эта переменная нужна, для Gradle — нет. Из PowerShell (`gradlew.bat`) проблемы нет.
- **Не опрашивать adb в цикле с частыми вызовами.** Цикл `until adb shell getprop …; sleep 3`
  забил порт 5037 тысячами соединений в TIME_WAIT: adb перестал стартовать, а эмулятор,
  запущенный в этот момент, не смог открыть порты 5554/5555 и остался невидим для adb.
  Ждать загрузку одной командой внутри устройства:
  `adb wait-for-device shell 'while [ "$(getprop sys.boot_completed)" != 1 ]; do sleep 2; done'`.
- PowerShell 5.1 читает `.ps1` без BOM как ANSI — кириллица в пути к JDK ломает скрипт.

**Про «медленно работает».** Замеры на эмуляторе без GPU давали холодный старт 8,4 с и
«Skipped 131 frames» — это отрисовка процессором, а не приложение. После включения GPU
перемерено с GPU: холодный старт 2,2–3,1 с (сразу после установки, без прогретого dex).
В коде уже убраны две настоящие задержки: синхронная запись настроек (`commit()` → `apply()`,
кроме кода очистки) и хеширование кода на главном потоке.

## 2. Решения владельца — переспрашивать не нужно

1. **Рекламы в первом релизе нет.** Пустой `zazor.admob.bannerUnitId` в `gradle.properties`,
   строка покупки скрыта. Код AdMob в сборке остаётся: включение — одна строка и версия.
2. **Firebase удалён полностью** (в проекте лежал чужой `google-services.json`, отчёты о сбоях
   уходили бы его владельцу). Библиотек Crashlytics и Analytics нет в зависимостях. Диагностика —
   Play Console («Качество → Сбои и ANR») плюс кнопка «Написать разработчику» в настройках.
3. **Код очистки работает молча**: стирает файлы, записи, пароль и сам код очистки; оплату Pro
   сохраняет (это деньги пользователя, а не улика).
4. **Снимок сохраняется в разрешении сенсора**, штамп рисуется на кадре; размер ограничен долей
   кучи приложения, а не фиксированным числом.
5. **Коды хранятся солёным хешем** (PBKDF2), геттеров нет.
6. **Триал удалён совсем** — на его месте «Написать разработчику».
7. **Ячейки коллажа вписывают кадр целиком** (не обрезают), поля — фон сетки.
8. **`.design/` — это ТЗ.** 16 экранов, их надо интегрировать полностью. Текст экранов удобно
   вытаскивать скриптом (см. раздел 5), полная разметка — в `.dc.html`.

### Сверка с макетом по пикселям

Приём, которым сверялись все экраны, — макет и снимок эмулятора рядом, в одном масштабе:

- `adb shell wm density 443` — тогда 1080 px экрана = 390 dp, ровно ширина макетов.
- `adb shell cmd locale set-app-locales com.gps.zazor --locales ru-RU` — макеты на русском,
  а система эмулятора может быть на любом языке; это не трогает сам эмулятор.
- Макеты рисуются в PNG headless-хромом:
  `chrome --headless=new --window-size=390,900 --screenshot=<файл> <файл.dc.html>`.
- Снимок экрана масштабируется до 390 и кладётся рядом с макетом, поверх — сетка через
  50 px. На AVD Android 15 вырез камеры даёт 46 px сверху — их надо отрезать, иначе всё
  «съедет» на эти 46.
- Геометрию макета (отступы, радиусы, кегли) удобно читать не глазами, а разбором
  `.dc.html`: это абсолютно спозиционированные блоки в кадре 390×844, один CSS-пиксель
  равен одному dp.

## 5. Остаток по дизайну

Текст всех экранов одним списком:

```powershell
Get-ChildItem .design -Filter *.dc.html | ForEach-Object {
  $b = [regex]::Match((Get-Content $_.FullName -Raw), '(?s)<x-dc>(.*)</x-dc>').Groups[1].Value
  $b = [regex]::Replace($b, '(?s)<svg.*?</svg>|(?s)<style.*?</style>', ' ')
  "=== $($_.Name)"; (($b -replace '<[^>]+>', "`n") -split "`n" | ForEach-Object { $_.Trim() } |
    Where-Object { $_.Length -gt 1 }) -join ' | '
}
```

| Экран | Состояние |
|---|---|
| Main (камера) | сверено: сигнал, меню, карточка штампа, стекло переключателя режимов |
| Editor | сверено: вкладки листа, инструменты, палитра, толщина |
| Series | сверено: кадры с точностью, «ТОЧКА» на лучшем, «Ещё кадр», «Передать серию» |
| Panorama | сверено: свой экран разбора — полоса кадра, карточка, «Метка», «Сохранить» |
| Gallery | сверено: фильтры, заголовок из заметки, азимут панорамы, вход в серию |
| History | сверено: карточка на день со следом, красная кнопка «удалить всё», примечание |
| Map | сверено: день, три показателя, выноска точки, лист с двумя кнопками |
| Share | сверено, кроме «ссылки со сроком жизни»: она требует своего сервера |
| Settings | сверено: группы, значения, значки и короткие названия строк |
| Disguise | сверено: выбор значка, подпись, красная строка кода очистки |
| Privacy | сверено; блок статистики скрыт, пока нет телеметрии |
| Support | сверено: форма внутри приложения, письмо уходит через почтовое приложение |
| Ads | **исключено владельцем из этого релиза** |
| Pro | **исключено вместе с рекламой** |
| LinkReady | **исключено: нужен свой сервер** |
| Dashboard | **исключено: нужны телеметрия и бэкенд, противоречит решению №2** |

Три места, где сделано **не** буквально по макету, и почему:

1. **Три точки-страницы под панорамой не рисуются.** Кадр один, листать нечего; точки,
   которые ничего не перелистывают, — украшение, притворяющееся управлением.
2. **Первая плитка в выборе значка показывает настоящую иконку приложения** (фотографию),
   а не синий квадрат с «Z» из макета. Смысл ряда — «вот что будет на домашнем экране».
3. **Значок «Компас» остался стрелкой в круге.** В макете на его плитке нарисованы
   вертикальные шевроны — это читается как «высота», а не как компас, и это настоящая
   иконка лаунчера, которую видно в 48dp.

Единственное, что осталось от дизайна внутри приложения, — это то, что владелец отложил
сам. Если реклама когда-нибудь включается, вместе с ней нужны экраны Ads и Pro.

## 7. Как проверять на эмуляторе

Полезный приём: снимать дерево экрана и бить по элементам по их идентификаторам, а не по
координатам.

```powershell
adb shell uiautomator dump /sdcard/ui.xml; adb shell cat /sdcard/ui.xml
```

Метаданные снимка проверяются разбором JPEG: в файле не должно быть сегмента APP1 (EXIF/XMP).
На живом телефоне то же самое подтверждается `exiftool`.
